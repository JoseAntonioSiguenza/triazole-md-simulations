# Triazole-MD-Simulations
This repository contains the code for the study "Molecular Docking and Molecular Dynamics Simulations of 4-Heteroarylidenamino-4,5-dihydro-1H-1,2,4-triazol-5-one Derivatives as Potential Cancer Inhibitors." It provides a reproducible workflow for molecular docking using AutoDock Vina and molecular dynamics (MD) simulations with OpenMM (10 ns, AMBER/GAFF), optimized for GPU and CPU execution.

The included input files correspond to PDB ID: 5M8Q (protein) and triazole compound 1D (ligand) from the study. However, the workflow is fully customizable, you can use any protein (PDB format) and ligand (SDF format).

# How to Use
To run this code, you can either download the files manually from this repository or use the following command in your terminal:


`git clone https://github.com/your-username/molecular-dynamics-docking.git`

Alternatively, in Google Colab, run:


`!git clone https://github.com/your-username/molecular-dynamics-docking.git`
