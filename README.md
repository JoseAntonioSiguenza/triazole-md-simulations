# triazole-md-simulations
This repository contains the code for the study "Molecular Docking and Molecular Dynamics Simulations of 4-Heteroarylidenamino-4,5-dihydro-1H-1,2,4-triazol-5-one Derivatives as Potential Cancer Inhibitors." It provides a reproducible workflow for docking (AutoDock Vina) and MD simulations (OpenMM, 10 ns, AMBER/GAFF) with GPU/CPU support.
